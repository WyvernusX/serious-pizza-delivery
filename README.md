## about
a 3d movement platformer where your only objective is to collect as many pizzas, as fast as possible. heavily inspired by ghostrunner (movement wise). 

## levels
level 1 -> easy level that combines all movement mechanics (not obstacles)\
level 2 -> level relying on jumps and dash, with them instantly refreshing when you land on a platform\
level 3 -> level relying on wallruns, and the mechanics that come with it (walldash, wallrun)\
level 4 -> level based primarily around moving obstacles\
level 5 -> combination of all previous mechanics into one tower level

## controls
wasd -> movement keys\
q -> dash\
shift -> run\
right command / meta -> crouch
